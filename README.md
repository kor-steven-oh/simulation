# 전략적 인력운영 통합 시스템

**“우리 사업부의 현재 인력 구조와 운영 현황은 사업전략에 최적화되어 있는가?”**

인력·조직·근태·역량·과제·비용 데이터를 연결해 전략 적합성을 진단하고, 시뮬레이션과 최적화로 경영진의 인력운영 판단을 지원하는 시스템 설계 문서입니다.

## 메인 문서

현재 설계의 기준은 아래 두 문서입니다. `v2.html`에서 시스템의 목적과 기능을 확인한 뒤, `agents.html`에서 Agent 협업과 데이터 처리 구조를 읽는 순서를 권장합니다.

| 문서 | 내용 |
| --- | --- |
| [v2.html](v2.html) | 시스템 기획안. 전략 적합성 판단 기준, 핵심 기능, 경영진 검토 시나리오, 통합 데이터, 시스템 구조, 화면·권한, 구축 로드맵 |
| [agents.html](agents.html) | AI Agent 아키텍처. 역할별 Agent와 중앙 조정 계층, 시뮬레이션·최적화 엔진, 대용량 데이터 접근·결과 전달, 검증, 초기 구축 범위 |

## 핵심 설계

- **전략 진단:** 사업전략이 요구하는 인력 구조·역량·투입량을 현재 상태와 비교합니다.
- **시뮬레이션:** 설정한 대안을 적용했을 때의 비용·인력 격차·일정 영향을 계산합니다.
- **최적화:** 목표와 제약조건에 맞는 배치·육성·채용·외주 조합을 탐색합니다.
- **Agent 협업:** 전략 해석, 인력 진단, 시뮬레이션, 최적화, 검증, 경영진 브리핑의 6개 역할을 정의하고, 초기 구현은 4개 Agent로 시작합니다.
- **대용량 데이터 처리:** DB와 계산 엔진이 분석 대상 데이터를 처리하고, Agent는 필요한 결과·예외·근거를 조회합니다.
- **경영진 의사결정 지원:** 현재 구조 유지안과 대안의 효과·비용·기간·불확실성을 같은 기준으로 비교합니다.

1. 저장소를 내려받은 뒤 `v2.html` 또는 `agents.html`을 브라우저에서 엽니다.
