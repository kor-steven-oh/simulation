01

설계 방향

핵심 질문은 “우리 사업부의 현재 인력 구조와 운영 현황은 사업전략에 최적화되어 있는가?”입니다. Agent는 이 질문을 분석 가능한 작업으로 나눕니다.

INTERPRET

Agent가 해석·설계

사업전략과 질문을 해석하고, 분석 범위·가정·대안을 구성합니다. 필요한 결과와 근거를 도구로 조회하고, 계산 결과의 의미를 설명합니다.

COMPUTE

공통 엔진이 계산·탐색

정의된 분석 범위의 데이터를 직접 읽어 인원·FTE·비용과 대안을 계산합니다. Agent에는 지표·예외·근거를 반환합니다.

DECIDE

경영진이 검토·판단

대안별 목표 충족 수준, 비용, 소요 기간과 불확실성을 보고 인력운영 방향과 우선순위를 판단합니다.

큰 흐름은 정해진 절차로, 각 단계의 분석은 Agent로.
중앙 조정 계층이 작업 순서·권한·재시도·종료 조건을 관리하고, Agent는 해당 단계에 허용된 도구로 분석합니다. 6개 Agent는 역할의 구분이며, 각각 별도 서버나 다른 AI 모델을 사용해야 한다는 의미는 아닙니다.

분석 범위와 기본 단위

사업부 인력 구조부터 분석

거점·직군·역량·월별 인력 규모와 투입량을 기본 단위로 합니다. 사업 특성에 따라 주 단위 분석을 추가합니다.

현재 구조 유지안을 공통 기준으로 사용

같은 사업계획·기간·데이터를 적용해 유지안과 대안의 효과·비용·잔여 격차를 비교합니다.

필요한 작업만 호출

단순 인원 조회에는 데이터 조회만 수행합니다. 전략 진단이나 대안 탐색이 필요한 질문에 해당 Agent를 연결합니다.

구조 수준의 대안에서 배치 가능성까지 확인

집계상 가능한 안도 실제 인력의 역량·시간·거점 조건에 맞는지 확인합니다. 구체화 단계에서 문제가 드러나면 상위 대안을 재검토합니다.

Agent별 책임과 산출물

AGENT 01 / STRATEGY

전략 해석 Agent

사업계획을 분석 가능한 목표와 인력 요구사항으로 구체화합니다.

입력
관련 사업계획 구간과 출처, 경영진 질문, 목표 기간·예산·우선순위
주요 작업·도구
전략 문서 조회, 요구사항 구조화, 미확인 항목 식별
역할 기준
“신사업 강화”를 핵심 과제·업무량·필요 역할·확보 시점으로 정리합니다. 인원 산정 기준은 사업·인사 담당자의 확인 여부를 표시합니다.
산출물전략별 요구사항 · 판단 기준 · 확인할 가정
AGENT 02 / DIAGNOSIS

인력 진단 Agent

현재 인력 구조와 전략별 요구 수준을 비교합니다.

입력
전략 요구사항, 조직·직군·기간별 집계표, 격차·예외 목록, 상세 조회 ID
주요 작업·도구
공통 지표 조회, 수요·공급 예측 호출, 격차·원인 가설 분석
역할 기준
인원 수가 충분해도 특정 역량이나 시점에 공급이 부족할 수 있습니다. 확인된 사실과 원인 가설을 구분합니다.
산출물전략 적합성 진단 · 부족·여유 영역 · 원인 가설
AGENT 03 / SIMULATION

시뮬레이션 Agent

설정한 대안과 조건 변화가 어떤 결과를 만드는지 분석합니다.

입력
유지안·후보안 ID와 변경 조건, 변동 가정, 시뮬레이션 결과 요약
주요 작업·도구
시뮬레이션 실행, 가정 변화 비교, 후보안의 변동 영향 분석
역할 기준
인력 이동이 지원받는 조직과 인력을 내주는 조직에 미치는 영향을 함께 계산하도록 요청합니다.
산출물대안별 예상 비용·부족량·일정 영향
AGENT 04 / OPTIMIZATION

최적화 Agent

목표와 제약을 정리하고 실행 가능한 조합을 탐색합니다.

입력
전략 목표·제약 정의, 현재 상태 요약과 데이터 참조, 후보안 요약·결과 ID
주요 작업·도구
최적화 엔진 호출, 후보안 비교, 충족하지 못한 조건 해석
역할 기준
필수 조건은 유지합니다. 조건 완화가 필요하면 기존 결과와 구분한 별도 검토안으로 제시합니다.
산출물인력 구조·배치·육성·채용·외주 후보안
AGENT 05 / VALIDATION

검증 Agent

입력·가정·계산 결과·설명이 서로 일치하는지 점검합니다.

입력
핵심 주장·계산 결과·출처, 조회 범위와 완전성 정보, 자동 검증 결과
주요 작업·도구
검증 서비스 호출, 근거 대조, 누락·과도한 해석 점검
역할 기준
숫자와 제약은 프로그램이 검사하고, Agent는 설명의 근거와 논리적 일관성을 점검합니다.
산출물검증 상태 · 수정 요청 · 남은 불확실성
AGENT 06 / BRIEFING

경영진 브리핑 Agent

검증된 결과를 경영진의 판단 자료로 구성합니다.

입력
검증된 결론·대안 비교표·근거 참조, 미해결 항목, 경영진 검토 맥락
주요 작업·도구
결과 요약, 대안 비교표 구성, 의사결정 쟁점 정리
역할 기준
새로운 수치를 만들어 넣지 않고 검증된 결과를 인용합니다. 생성한 설명도 출처·수치 일치 검사를 거쳐 제시합니다.
산출물핵심 쟁점 · 대안 비교표 · 판단 근거

같은 모델을 사용하더라도 Agent별 지시사항, 도구, 입력 범위, 출력 형식을 구분합니다. 여러 Agent를 두는 것만으로 입력 용량 문제가 해결되지는 않습니다. Agent 간에는 분석 ID·핵심 결과·근거 위치·남은 질문을 전달합니다.

03

시뮬레이션·최적화 엔진

Agent는 분석 조건과 대안을 설계합니다. 실제 수치 계산과 조합 탐색은 공통 엔진이 수행합니다.

구분F05 · 시뮬레이션 AgentF06 · 최적화 Agent
담당 질문이 대안을 적용하면 어떻게 되는가?목표와 제약에 맞는 대안은 무엇인가?
입력구체적인 배치·육성·채용·외주안과 가정목표·우선순위·예산·운영 제약
작업설정한 대안의 결과와 가정 변화의 영향 계산가능한 조합을 탐색하도록 최적화 엔진 호출
결과대안별 비용·부족량·일정 영향조건을 만족하는 후보안과 목표 간 상충관계
연결최적화 후보안도 같은 방식으로 평가평가 결과를 바탕으로 추가 탐색 필요성 검토
협업 예시
시뮬레이션: “A조직에서 B조직으로 3명을 이동하면 두 조직에 어떤 변화가 생기는가?”
최적화: “기존 조직의 최소 운영 인원을 유지하면서 신사업 인력 부족을 줄일 조합은 무엇인가?”
후속 시뮬레이션: “제안된 조합에서 채용이 한 달 늦어져도 수행 가능한가?”
인원·기간은 역할 설명을 위한 가정입니다.

공통 계산·분석 서비스

공통 서비스처리할 내용결과의 기준
데이터 조회·지표분석 대상 기록을 조회·집계해 인원, FTE, 배정량, 추가 배정 여력, 비용 계산동일 기간·조직·집계 기준과 누락 정보 표시
수요·공급 예측업무량 전망, 필요 인력, 확정 입사·복귀 등 공급 변화확정 계획과 예측 구분, 가정·오차 표시
시뮬레이션기간별 인력·비용·수행 가능량의 변화대안과 가정을 명시하고 유지안과 비교
최적화목표와 제약을 반영한 배치·육성·채용·외주 조합 탐색탐색 결과 상태, 충족 조건, 목적값 기록
검증중복 배정, 필수 역량 누락, 예산 초과, 집계 불일치 검사검사 규칙별 통과·실패와 근거 반환
데이터 접근·결과 전달요청 범위·권한 검증, 집계·예외·상세 조회 ID로 결과 구성입력 크기 제한, 전체·일부 결과 구분, 추가 조회 경로 제공
최적화 모델은 검증된 구조로 구성합니다.
Agent가 정리한 목표·조건은 입력 형식과 허용 범위를 검사한 뒤, 사전에 구현·검증한 모델에 전달합니다. 엔진은 허용된 데이터 참조로 필요한 인력·역량·제약 기록을 직접 읽고, 대규모 배치표는 결과 저장소에 보관합니다. 예를 들어 OR-Tools와 같은 도구로 배정 변수·제약·목표를 정의할 수 있습니다. OR-Tools 인력 스케줄링 예제 ↗

최적화 결과를 구분해 전달

탐색 결과경영진에게 전달할 의미
최적성 확인설정한 모델과 목표 안에서 최적성이 확인된 안입니다. 가정의 현실 적합성은 별도로 검토합니다.
실행 가능한 안 발견조건을 만족하는 안을 찾았지만 최적성은 아직 확인되지 않았습니다.
해 없음 확인설정한 필수 조건을 동시에 만족하는 안이 없음을 확인했습니다. 충돌 원인 분석과 조건 조정 검토가 필요합니다.
시간 제한·결과 미확정정해진 시간 안에 가능 여부를 결론 내리지 못했습니다. 해가 없다는 의미로 해석하지 않습니다.

  2. DB와 엔진에서 대상 전체 계산

    관련 인력·역량·배정·근태 기록을 연결해 직군·역량·기간별 필요량, 공급량, 부족량과 비용을 계산합니다.

  3. 집계표와 예외를 먼저 전달

    Agent에는 조직·직군·월별 결과표와 부족·누락·과부하 목록을 반환합니다. 상세 기록은 결과 ID로 참조합니다.

  4. 필요한 원인만 상세 재조회

    격차가 나타난 조직·역량·기간으로 범위를 좁혀 근거를 확인하고, 검증된 결론을 경영진에게 설명합니다.

기록 규모는 구조 설명을 위한 가정입니다. 실제 처리 성능은 데이터 구조, 기간, 조회 방식과 최적화 조건으로 검증해야 합니다.

전체 계산과 상세 검토 연결

전체 대상 집계와 조건 검사는 엔진에서 수행합니다. 예외 목록이 일부만 반환되면 남은 범위를 표시하고, 검토가 끝나지 않은 결론은 범위를 제한합니다.

최적화 처리 한계

인원·기간·역량·거점·제약 조합에 따라 탐색 부담이 커집니다. 집계 단위에서 후보안을 만든 뒤 실제 배치 가능성을 확인하고, 공유 인력·예산은 통합 제약으로 유지합니다.

확정된 인사 정보와 채용·이동 가정을 구분합니다. 후보안은 별도 시나리오로 저장하고 인사 원장을 변경하지 않습니다.

필요한 정보만 전달

Agent에는 해당 작업의 핵심 결과·근거 참조·남은 질문을 전달합니다. 계산 입력과 상세 결과는 저장소에 유지하고, Agent가 이어받을 때도 동일한 버전과 접근 범위를 적용합니다.

권한은 조회 서비스에서 적용

조직·개인·급여·근태별 접근 범위를 데이터 조회 시점에 적용합니다. Agent가 다른 Agent를 호출해도 원래 요청자의 접근 범위를 유지합니다.

가정 변경은 새 버전으로 기록

같은 후보안 이름이라도 예산·업무량·입사 시점이 달라지면 결과를 구분합니다. 공통 가정이 변경되면 유지안도 함께 재계산합니다.

예시 · “채용이 한 달 지연되는 경우”는 별도 시나리오로 비교할 수 있습니다. 확정된 최소 운영 인원을 낮춰야 하는 경우에는 변경 조건과 영향을 명시한 검토안으로 제시합니다.
06

실행 제어와 검증

중앙 조정 계층은 작업 순서와 상태를 관리하는 서비스입니다. 질문 해석에 AI를 활용하더라도 실행·권한·종료 조건은 코드로 통제합니다.

조정 책임설계 방식
범위 고정분석 시작 시 사업부·기간·전략·데이터 버전을 고정하고 모든 작업에 전달합니다.
작업 선택현황 조회, 전략 진단, 시뮬레이션, 최적화 중 필요한 경로를 선택합니다.
입력·반환량 관리Agent별 입력과 도구 반환량을 제한하고, 초과하는 결과는 범위·선택 기준을 표시한 집계·예외·상세 조회 ID로 반환합니다.
병렬 실행서로 독립적인 거점별 진단이나 같은 기준의 대안 계산을 병렬 처리합니다.
의존 관계 관리진단 결과를 받은 뒤 대안을 설계하고, 최적화 후보안을 받은 뒤 후속 시뮬레이션을 수행합니다.
재시도·재분석일시적인 도구 오류는 제한적으로 재시도하고, 입력 변경 시 영향받는 단계와 후속 결과를 다시 계산합니다.
종료·보류반복 횟수·시간·비용 한도를 두고, 필수 데이터가 없거나 판단 기준이 불명확하면 해당 분석을 보류합니다.
공유 자원은 전체 조건을 함께 봅니다.
거점별 진단은 병렬로 수행할 수 있지만, 같은 인력이나 예산을 공유하는 배치 최적화는 통합 조건으로 계산해야 합니다. 각 Agent가 같은 사람을 독립적으로 배정하는 중복을 방지합니다.

07

실제 분석 시나리오

하나의 경영 질문이 각 Agent의 산출물로 이어지고, 최종적으로 비교 가능한 판단 자료가 됩니다.

“내년 신사업 확대 전략을 현재 인력 구조로 수행할 수 있는가?
추가 예산 범위 안에서 대안을 제시해줘.”실제 사업·인사 데이터를 적용하기 전의 설명용 시나리오입니다.

분석 한 건의 진행 순서

  1. 전략 해석

    신사업 목표, 대상 기간, 요구 역량, 추가 예산과 우선순위를 정리합니다. 확인되지 않은 요구량은 가정으로 구분합니다.

  2. 현재 구조 진단

    엔진이 대상 데이터를 직접 읽어 유지안의 수행 가능량을 계산합니다. Agent는 조직·역량·기간별 집계와 예외를 받고, 격차가 있는 범위의 상세 근거를 재조회합니다.

  3. 유지안·설정한 대안 시뮬레이션

    현상 유지안과 검토자가 제시한 이동·채용·외주안의 결과를 같은 기간과 기준으로 계산합니다.

  4. 최적화 후보안 탐색

    내부 이동·육성·채용·외주를 조합해 목표와 제약에 맞는 후보안을 찾습니다. 해가 없거나 탐색이 미완료이면 상태를 명시합니다.

  5. 후보안의 조건 변화 검토

    채용 지연이나 업무량 증가를 후보안에 적용하고, 유지안과 함께 다시 계산해 결과의 변화를 비교합니다.

  6. 수치·제약·설명 검증

    동일 기준의 비교인지, 제약을 충족하는지, 모든 핵심 주장에 근거가 있는지 확인합니다.

  7. 경영진 브리핑

    전략 적합성, 주요 격차, 유지안 대비 효과·비용·기간, 잔여 위험과 판단할 사항을 제시합니다.

경영진에게 제시할 비교표의 구성

전략 목표 충족 수준현재 구조에서의 예상 충족 수준유지안 대비 개선·악화되는 목표와 정도

총비용·소요 기간현재 계획 기준 비용·일정인건비·채용·교육·외주·이동 비용과 전환 기간
남는 격차·위험조치하지 않을 경우의 격차조정 이후에도 남는 부족과 조건 변화의 영향

위 표는 산출물의 형식이며 실제 분석 결과가 아닙니다. 경영진이 우선순위나 예산을 바꾸면 변경 조건으로 후보안을 다시 탐색합니다.

초기 구축과 확장

논리적인 역할은 6개로 설계하되, 초기 구현은 4개 Agent와 공통 서비스로 시작합니다.

MVP AGENT 01

전략·진단

전략 해석과 인력 진단을 묶어, 요구 수준과 현재 상태의 격차를 정리합니다.

확장 시
전략 문서·사업 범위가 복잡해지면 두 역할을 분리합니다.

MVP AGENT 02

시뮬레이션

설정한 대안의 결과와 조건 변화의 영향을 계산 엔진으로 평가합니다.

기본 유지
최적화 후보안의 후속 검토도 담당합니다.

MVP AGENT 03

최적화

목표·제약을 구조화하고 검증된 최적화 모델로 후보안을 탐색합니다.

기본 유지
분석 규모에 맞춰 모델과 탐색 범위를 확장합니다.

MVP AGENT 04

검증

자동 검사 결과와 분석 근거를 대조해 최종 설명의 일관성을 검토합니다.

기본 유지
후보안을 생성하는 역할과 검증 역할을 분리합니다.

초기 브리핑은 검증된 결과를 정해진 양식으로 작성합니다.
자료 형식과 질문 유형이 늘어나면 경영진 브리핑 Agent를 분리합니다. 중앙 조정 계층·데이터 접근·결과 전달 계층·계산 엔진·검증 서비스는 초기부터 공통 기반으로 구성합니다.

한 사업부의 일부 거점·핵심 직군과 하나의 전략 과제를 선정합니다. 합의한 계획 기간을 대상으로 현재 구조 유지안, 검토자가 설정한 대안, 최적화 후보안을 같은 기준으로 비교합니다.

기준과 계산의 일관성

전략 요구량·인력·비용이 원천 근거와 연결되고, 동일한 조건의 계산을 재현할 수 있는지 확인합니다. 일부 결과만 반환해도 전체 집계와 상세 조회의 값이 일치해야 합니다.

제약 충족과 예외 처리

중복 배정·필수 역량·예산을 검사하고, 데이터 부족·해 없음·시간 제한을 서로 구분하는지 확인합니다.

시뮬레이션과 최적화의 연결

엔진이 반환한 후보안을 동일한 시뮬레이션 기준으로 평가하고, 가정 변경 시 필요한 결과가 갱신되는지 확인합니다.

경영진 판단에 필요한 근거

유지안 대비 효과·비용·기간·잔여 위험을 비교할 수 있고, 모든 핵심 결론에 출처가 연결되는지 확인합니다.

대용량·부분 결과 처리

데이터가 늘어도 Agent 입력 한도가 유지되는지, 상위 일부 반환·누락·부분 처리가 명시되는지, 예외와 상세 근거를 다시 조회할 수 있는지 확인합니다.

조회·계산 성능

대표 데이터 규모에서 조회 시간·반환량·Agent 입력량·최적화 탐색 시간을 측정합니다. 허용 기준은 실제 데이터와 업무 주기에 맞춰 정합니다.
